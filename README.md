# User Analysis System / Kullanıcı Analiz Sistemi

A simple Python-based user management and age analysis system.
Python tabanlı basit bir kullanıcı yönetim ve yaş analiz sistemi.

---

# Features / Özellikler

* Add users / Kullanıcı ekleme
* Store users in JSON / Verileri JSON dosyasında saklama
* Age analysis with NumPy / NumPy ile yaş analizi
* Logging system / Log sistemi
* Exception handling / Hata yönetimi
* Menu-based terminal interface / Menü tabanlı terminal arayüzü
* Object-oriented programming structure / Nesne yönelimli programlama yapısı

---

# Technologies Used / Kullanılan Teknolojiler

* Python
* NumPy
* JSON
* Logging Module
